# CodeRadar 测试与验证报告

## 1. 当前结论

CodeRadar 主体代码的最近一次离线全量回归结果为 258 项通过、1 项网络测试未选择、4 条 `feedparser` 弃用警告。该结果覆盖采集、处理、模式校验、切分、索引别名、混合检索、排序、证据、评测、接口和命令行。

当前 `data/cleaned/documents.jsonl` 包含 1,077 个文档版本，文件大小为 4,412,343 字节，SHA-256（Secure Hash Algorithm 256-bit，256 位安全散列算法）为 `0893637a61c62b55dcba8bb40d11bb0f38e6a7dd20eaf227eb4e8bb561c57c5f`。最近 90 天的竞品与事件类型覆盖矩阵有 14/15 个组合具备证据。Mini-RAG 索引和正式检索评测未基于该数据版本重建，因此代码回归、结构化数据、读取别名和保存评测分别具有独立的版本边界。

## 2. 验证范围

下表说明自动化测试覆盖的主要对象。

| 测试域 | 主要验证内容 |
| --- | --- |
| 采集 | HTTP（Hypertext Transfer Protocol，超文本传输协议）缓存、限速、重试、浏览器回退、GitHub、RSS（Really Simple Syndication，简易信息聚合）、更新日志与存储 |
| 处理 | 清洗、规范化、事件与维度标签、去重、版本区间和原子重建 |
| 数据契约 | `RawRecord`、`StructuredDocument`、Chunk、查询、证据和评测模型 |
| Mini-RAG | 来源感知切分、BM25、稠密检索、RRF、重排序、时间版本排序和证据排序 |
| 索引 | 版本化索引、别名切换、增量同步、嵌入元数据兼容性 |
| 证据 | 引用生成、引用白名单校验、冲突检测和查询轨迹 |
| 接口 | 查询、证据、轨迹、索引、评测、错误码和 UTF-8 响应 |
| 评测 | Recall、MRR、nDCG、过滤准确率、引用正确率、消融和汇总 |

RRF 指倒数排名融合（Reciprocal Rank Fusion）；MRR 指平均倒数排名（Mean Reciprocal Rank）；nDCG 指归一化折损累计增益（Normalized Discounted Cumulative Gain）。

## 7. 验证边界

当前验证状态由四组结果组成：

1. 离线代码回归为 258 项通过、1 项网络测试未选择；
2. 结构化数据为 1,077 个版本，数据 SHA-256 已记录；
3. 最近 90 天的证据覆盖为 14/15；
4. Mini-RAG 索引和正式检索评测尚未随当前数据重建。

代码测试结果验证实现行为，文档审计验证结构化数据契约，覆盖审计验证竞品与事件组合，索引状态验证可检索 Chunk。四组结果只有在数据哈希、配置、物理索引和评测集一致时，才能组成同一轮完整验收。

## 8. 复现命令

离线主体回归命令：

```powershell
Set-Location D:\26Spring\project\CodeRadar
& .\.venv\Scripts\python.exe -m pytest -m 'not network' -q
```

数据审计与索引状态命令：

```powershell
& .\.venv\Scripts\python.exe -m scripts.audit_documents
Get-FileHash .\data\cleaned\documents.jsonl -Algorithm SHA256

& .\.venv\Scripts\python.exe -m scripts.audit_evidence_coverage `
  --competitors all `
  --event-types product_release,pricing_change,risk_experience `
  --as-of 2026-07-26 `
  --window-days 90

Invoke-RestMethod http://127.0.0.1:8000/ready
Invoke-RestMethod http://127.0.0.1:9200/_cat/aliases/coderadar_chunks_current?v
```

这些命令会分别验证代码、结构化数据和运行索引。完整验收需要三组结果属于同一数据哈希、同一索引版本和同一配置版本。

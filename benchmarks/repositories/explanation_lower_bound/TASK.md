# bench_007：解释 lower_bound 的循环不变式与边界

阅读 `lower_bound.py`，将 `RESPONSE.md` 改写为一份面向大一学生的中文解释。

回答必须覆盖：

- `[lo, hi)` 左闭右开搜索区间及每轮循环不变式；
- `values[mid] < target` 两个分支为何分别更新 `lo = mid + 1` 与 `hi = mid`；
- 循环为什么终止，以及终止时 `lo == hi` 为什么是插入位置；
- 时间复杂度 `O(log n)` 和空间复杂度；
- 至少两个边界例子，必须涉及空数组、重复元素、目标小于全部元素、目标大于全部元素中的两类；
- 至少一个常见错误及其后果。

`validate.py` 只检查可自动判定的最低门槛。最终分数由两名不知道产品名称的评审者分别依据 `rubric.json` 打分，再按 `merge_rule.json` 合并。不得修改验证器、量表或评审模板。

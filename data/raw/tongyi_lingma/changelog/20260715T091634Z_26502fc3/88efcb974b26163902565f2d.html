0.6.7（2026-07-01）

声纹识别，只写你自己的话

语音输入接入声纹识别，开启后周围人声不再被误录进转写；docx / pptx 内置技能和知识库上传也做了系统性升级。

新功能

  • 语音输入声纹识别
    在语音输入设置里打开「声纹识别」开关（默认关闭），每次录音开始时会自动学习你这段话的说话特征，随后旁人说话、远处交谈、环境噪声都会被压掉，只留下你自己的声音进入转写和后续润色。开会、咖啡店、家里有人说话都不再被误录。

  • docx / pptx 内置技能升级
    用一句话就能生成规范的 Word 和 PPT：docx 新增模板填充、Markdown 直接转 DOCX，pptx 生成更稳定，产物也更整洁。

  • 知识库 ZIP 上传与大文件直传
    知识库支持整包 ZIP 上传，大文件走直传通道，成功率和速度都更好。

  • Dock / 任务栏未读状态
    macOS 与 Windows 都可以在设置里控制 Dock / 任务栏图标是否显示未读提示。

改进

  • 模型上下文窗口设置弹窗
    在模型选择器里给每个模型单独设置上下文窗口的弹窗做了一轮优化，字段更清楚、切换更顺手。

  • 连接器市场分流
    连接器、技能、插件市场按产品和版本分流，只展示当前版本可用的条目。

  • 聊天内 MCP App 全屏
    对话里的 MCP App 现在支持切换全屏，右侧画布状态保持不丢。

  • 个人资源包增购入口
    在设置和用量总览里都能直接进入个人资源包增购。

修复

  • 修复知识库、连接器市场、MCP App 等模块的若干体验问题

  • 提升 Windows 更新流程与整体使用稳定性

0.6.6（2026-06-28）

上下文窗口支持 1M

这个版本新增了上下文窗口设置——每个模型可单独配置上下文长度，最大支持 1M。语音输入也做了大幅改进，快捷键录完自动发送、润色响应更快。

新功能

  • 上下文窗口设置
    模型选择器底部新增「模型设置」入口，可为每个模型单独设置上下文窗口长度（最大支持 1M），设置后全局生效。

  • 语音快捷键自动发送
    按一下快捷键开始录音，再按一下结束后直接发送。之前结束录音还需要手动点发送，现在一步到位。

改进

  • 语音润色更快上屏
    语音转写完成后润色结果几乎同步出现，不再有额外等待。

  • 归档提示更清晰
    归档确认弹窗新增「设置 → 已归档」路径提示，归档后知道去哪儿找。

  • 代码高亮语言扩充
    Markdown 预览新增多种高频编程语言的语法高亮支持。

修复

  • 修复 Windows 安装类型误判导致更新包错配、快捷方式失效和浏览器连接器路径异常

  • 修复系统代理不可用时网络连接中断的问题

  • 修复若干界面细节问题，包括 HTML 预览白屏、语音预览溢出、粘贴格式残留等

写作工作台和幻灯片工作台来啦！

写作工作台和幻灯片工作台正式开放——从一段想法到一篇成稿、从几行 prompt 到一份可放映的 PPT，都在 QoderWork CN 里一站完成。

  • 写作工作台

带来全新的写作工作台。把想法变成专业内容，从此不再卡在那块空白页。

在输入框切换到「写作」模式，告诉它你要写什么——博客、周报、产品文档、邮件——QoderWork CN 会规划结构、生成正文，并在右侧实时预览。可以挑选不同的写作语气（专业、亲切、活泼……），随时调整段落、改写句子、调整样式。写作过程中需要查资料、抓数据、引用图表，都能让它直接调用 MCP 工具完成。写完一键导出，或继续在 QoderWork CN 里迭代。

例如，一位运营同学要写一篇产品发布稿：切到写作模式，描述发布要点和受众，几秒内拿到结构清晰的初稿，再选「亲切」语气重写一遍，调一调标题层级，整篇稿子就齐了。

带来全新的幻灯片工作台。一句话生成一份可以直接放映的 PPT。

在输入框切换到「幻灯片」模式，描述选题和受众，QoderWork CN 会自动规划页面、生成内容、套上配套的视觉模板，并在右侧实时预览每一页。可以挑选不同风格的模板，预览每一页的草稿，确认后一次性产出。生成后支持全屏放映、HTML 离线导出，方便带到任何会议室直接讲。

例如，临时被通知要做一场分享：切到幻灯片模式，描述主题和大纲，QoderWork CN 几秒内生成完整 PPT 并实时预览，挑一个喜欢的模板，全屏播放就能直接开讲。

0.5.0（2026-05-19）

Hello, World!

我是 QoderWork CN，很高兴遇见你。

我是运行在你电脑上的 AI 同事，不止聊天，搞定一切！我可以帮你撰写文档、分析数据、整理文件，我不会只告诉你怎么做，而是替你执行。下面是我们可以一起做的事：

  • 替你执行，端到端交付

不是告诉你"你可以这样做"，而是直接做出来。把目标说给我听，我会自主规划、调用工具、产出最终结果。每一步都看得见、可中止。

  • 连接你的工作系统，像同事一样协作

通过开箱即用的连接器，我可以直接连接和操作你日常使用的办公工具——钉钉、飞书、邮箱、日历、本地文件，甚至操控你的浏览器和电脑。一次授权，长期协作，像一位随时在线的同事。

  • 为每一个岗位，提供专业能力

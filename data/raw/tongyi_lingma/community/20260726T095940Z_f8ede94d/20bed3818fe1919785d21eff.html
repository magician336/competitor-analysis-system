    阿里云通义灵码是目前的Qoder CN，Qoder CN 是阿里云推出的 AI 智能体产品系列，覆盖软件开发与日常办公多元场景，包含面向编码场景的 Qoder CN（含 IDE、JetBrains/VS Code 插件）、面向日常工作的 QoderWork CN（桌面应用）、Qoder CN CLI （终端原生形态）等子产品。官网链接：https://t.aliyun.com/U/fEiOLV

    阿里云通义灵码（Lingma）是阿里云推出的基于通义大模型的智能编码辅助工具，属于 Qoder CN 系列产品，旨在通过 AI 能力提升开发者编码效率与质量。

    一、通义灵码的核心能力包括：

    • 代码生成：根据自然语言描述生成完整函数或代码片段；
    • 代码续写：在编辑器中实时提供行级/函数级代码补全建议；
    • 代码解释：对选中代码自动解释其功能逻辑；
    • 代码优化与重构：识别潜在问题并提供更安全、规范的改写方案；
    • 单元测试生成：为指定函数自动生成测试用例；
    • 代码注释生成：自动为无注释代码添加清晰说明；
    • 研发智能问答：支持结合项目上下文回答技术问题；
    • 企业级增强：支持私有代码库感知、企业知识库问答、自定义指令等（企业版）。

    二、如何使用通义灵码？

    1. 在 DSW（交互式建模）中使用

    • 创建并启动 DSW 实例后，切换至 WebIDE；
    • 左侧点击通义灵码图标，在侧边栏输入需求（如“编写调用 qwen-plus 的 Python 代码”）；
    • 支持代码插入、复制、运行（需安装 openai 包并配置 API Key）；
    • 右键选中代码可执行 Explain（解释）、Optimize（优化）、UnitTest（生成测试）、Comment（生成注释） 等操作；
    • 行内续写以灰色文本提示，按 Tab 键采纳。

    DSW 内置的是通义灵码个人版，当前可免费使用。

    2. 在本地 IDE 中使用（VS Code / JetBrains）

    • 安装官方通义灵码插件；
    • 登录阿里云账号后自动激活；
    • 使用方式与 DSW 类似，支持侧边栏对话、右键操作、行内补全；
    • 企业版用户可使用 / 唤起自定义指令（如生成 API 文档、变量命名等）。

    3. 企业高级功能（企业标准版/专属版）

    • 企业代码补全增强：结合企业私有代码库，提升补全贴合度；
    • 企业知识库问答：上传内部文档，实现基于私域知识的精准问答；
    • MCP 服务集成：联动云效 DevOps、高德地图、MasterGo 等外部服务，实现“根据设计稿生成前端代码”“根据工作项自动生成代码并提交 MR”等自动化流程。

    三、账号与权限

    • 无需单独注册，直接使用阿里云账号登录；
    • 在 DSW 中，系统自动以实例创建者（Owner）身份启用通义灵码；
    • 企业版需在组织内授权开发者，并由管理员配置扩展指令与知识库。

    四、安全与合规

    • 不存储用户代码：代码上下文仅用于实时补全，不会被保存或用于其他用途；
    • 支持敏感信息过滤、私有化部署、VPC 网络隔离，满足金融、政务等高合规场景需求。

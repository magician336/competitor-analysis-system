重新绑定快捷键

  1. 在 Qoder CN IDE 的右上角，单击用户图标或使用键盘快捷键（⌘ ⇧ ,（macOS）或Ctrl shift ,（Windows）），然后选择个人设置。

  2. 单击通用，打开偏好 > 键盘快捷键，在搜索框中键入搜索按键绑定，在搜索结果中单击目标快捷键前的进行修改，然后单击Enter。

开启行间建议预测

在Qoder CN IDE的右上角，单击用户图标 或使用快捷键（⌘ ⇧ ,（macOS）或Ctrl shift ,（Windows）），选择个人设置，开启行间建议预测（NES）。

重要

Qoder CN IDE仅支持Auto模式，在该模式下IDE会根据场景自行选择Inline或Side by Side方式。

自定义项目专属规则

  1. 在 Qoder CN IDE 的右上角，单击用户图标或使用键盘快捷键（⌘ ⇧ ,（macOS）或Ctrl shift ,（Windows）），然后选择个人设置。

  2. 在左侧导航栏中，单击规则。

  3. 单击“添加”。

  4. 在顶部的搜索栏中，输入唯一的规则名称，然后按Enter。

  5. 选择规则类型：

    • 手动引入：仅通过@rule手动引入才生效。

    • 模型决策：输入期望规则生效的场景描述。

    • 指定文件生效：提供以逗号分隔的文件路径通配符。例如  *.md、  src/*.java。

    • 始终生效：在智能会话与行间会话的所有请求中均生效。

  6. 关闭窗口以保存更改。

重新绑定快捷键

  1. 在 Visual Studio Code 的首选项中，单击快捷键的设置入口；

    具体路径为顶部菜单栏依次单击 Code > Preferences > Keyboard Shortcuts，也可通过快捷键 ⌘K ⌘S 直接打开。

  2. 在快捷键管理窗口中，输入 Qoder CN 搜索，单击编辑。在弹出的窗口中输入用于命令的按键，然后单击Enter/Return。

启用或禁用行间生成

可以通过 2 个方法启用或禁用行间生成功能：

方法 1：单击状态栏的Qoder CN图标，在弹出的窗口中可快速启用或禁用行间生成功能：

  • 可以配置本地离线模型、云端大模型是否启用；

  • 开启本地离线模型、云端大模型同时开启的情况下，行间生成时优先推荐云端大模型的代码建议；

    单击VS Code右下角的Lingma图标，在弹出的Lingma Status面板中，勾选或取消勾选Cloud Model Auto Trigger即可启用或禁用行间补全。

方法 2：在设置页面启用或禁用行间生成，并支持设置生成的长度。

单击 LINGMA 面板顶部的齿轮图标进入设置页面。云端大模型相关配置项包括 Cloud Model Enable（启用云端模型）、Cloud Model Auto Trigger Generate Length 和 Cloud Model Manual Trigger Generate Length（分别设置自动触发与手动触发的生成长度，可选 Medium 等）、Cloud Model Auto Trigger Display Rule。本地离线模型相关配置项包括 Local Machine Model（启用本地模型补全）、Local Machine Model Inference Mode（推理模式，如 Auto Mode）和 Local Machine Model Max Candidate Num（最大候选数量）。

启用或禁用函数的行间快捷入口

Qoder CN的智能问答窗口中，单击设置，找到 Inline Chat Entry For Function（函数的行间快捷入口）配置项，勾选即可启用，取消勾选即可禁用该功能。

配置 IDE 原生补全和行间生成的展示规则

打开设置页面，可以设置是否同时展示行间自动生成建议和 IDE 原生下拉补全，默认不勾选。

该设置项为 Lingma: Cloud Model Auto Trigger Display Rule，对应选项为 Show inline suggestions when the IDE autocompletes shown。

JetBrains IDEs 中配置Qoder CN

使用Qoder CN时，可以在 JetBrains IDE 中使用默认快捷键使用Qoder CN相关功能。同时，您也可以重新修改命令的快捷键。有关在 JetBrains IDE 中重新绑定快捷键的详细信息，可参阅 JetBrains 文档，如可以查看IntelliJ IDEA文档。

重新绑定快捷键

  1. 打开 JetBrains IDEs 偏好设置。以 IntelliJ IDEA 为例：

    在 IntelliJ IDEA 顶部菜单栏单击 IntelliJ IDEA，在下拉菜单中单击 Preferences...（快捷键 ⌘,）。

  2. 在设置窗口中单击快捷键，输入面板（英文：Panel）后搜索，找到 Qoder CN 快捷键，右键后单击修改键盘快捷键。在弹出的窗口中输入用于命令的按键后，单击确定即可。

启用或禁用行间生成

方法 1：单击状态栏的Qoder CN图标，在弹出的窗口中可快速启用或禁用行间生成功能：

  • 可以配置本地离线模型、云端大模型是否启用；

  • 开启本地离线模型、云端大模型同时开启的情况下，行间生成时优先推荐云端大模型的代码建议；

    单击底部状态栏的 Lingma 图标，在弹出的 Lingma Status 菜单的 Completion Settings 区域中，单击 Local Machine Model 选项即可启用或禁用本地模型的行间补全功能。

方法 2：打开设置页面，支持启用或禁用行间生成，以及设置生成的长度。

在 Settings 对话框左侧单击 Lingma，在右侧 Completion Settings 区域中，勾选或取消 Enable Local Machine Model 和 Enable Cloud Model 以启用或禁用对应模型，通过 Code Completion Length 选择生成长度模式（Auto Mode、Speed First 或 Whole-line First），并可设置 Completion Length of Auto Trigger 和 Completion Length of Manual Trigger（手动触发快捷键为 ⌥P）。

启用或禁用函数的行间快捷入口

打开设置页面，支持启用或禁用函数的行间快捷入口。

在 Settings 面板左侧导航中选择 Tools > Lingma，在右侧找到 Method quick operation，选择 Enabled 或 Disabled。

配置 IDE 原生补全和行间生成的展示规则

打开设置页面，可以设置是否同时展示行间自动生成建议和 IDE 原生下拉补全，默认不勾选。

在 Preferences 设置对话框左侧分类树底部选择 Lingma，在右侧 Completion Settings 区域找到 Show inline suggestions when the IDE autocompletes 复选框并按需勾选。

查看帮助和分享反馈

查看使用帮助

Qoder CN的智能问答窗口中，可以单击智能问答窗口的帮助文档入口，可以快速来到当前帮助文档知识库。

智能问答窗口支持侧边栏内嵌面板和独立浮窗两种展示形式，面板顶部包含刷新、帮助、固定、设置等图标按钮，可通过快捷键 Ctrl+Shift+L 打开或关闭面板。

反馈回答质量

在智能问答中，你可以对Qoder CN所生成的回答内容进行评价，支持点赞和点踩，以不断优化回答效果。

使用问题反馈

当您在使用的过程有任何疑问、优化建议、功能诉求等，均可在Qoder CN的智能问答窗口单击提交反馈，即可前往阿里云开发者社区-Qoder CN问答专区向我们提出问题。

在 Visual Studio Code 中，单击 LINGMA 侧边栏顶部工具栏中的反馈图标即可提交反馈；在 JetBrains IDEs 中，单击 AI Chat 工具窗口右上角的反馈图标即可提交反馈。

参与体验调研

为了给您提供更好的智能编码体验，我们也期待收到您的使用体验反馈、优化建议以及您的期待，我们会不断努力和优化产品体验。

在 VS Code 中打开 Lingma 聊天面板，在欢迎语中单击 share feedback 链接即可提交使用体验反馈。

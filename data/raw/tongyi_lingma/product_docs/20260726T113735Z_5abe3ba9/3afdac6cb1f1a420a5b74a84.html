企业专属版登录

更新时间：
复制 MD 格式
产品详情
我的收藏

Qoder CN企业专属版开发者可以使用专属版的账号登录Qoder CN，本文介绍企业专属版开发者登录操作指南。

前提条件

  • 已成功获得Qoder CN企业专属版的用户账号，如果尚未获得专属版的用户账号，可联系企业管理员获取；如果企业内已完成用户身份SSO配置，可根据企业账号使用方式进行登录。

  • 已在企业中被授权Qoder CN开发者权限，如需获得权限，可联系企业内的Qoder CN管理员添加权限，可参考：授权管理。

  • 已在JetBrains IDEs、Visual Studio Code、Visual Studio中安装Qoder CNIDE插件、或下载安装 Qoder CN IDE，具体操作可参考：安装指南。

登录Qoder CN

步骤一：获取专属版登录地址

您可联系企业管理员，获取专属版的登录地址。企业管理员可通过如下步骤获取：

  1. 阿里云主账号或有云效管理权限的RAM账号，进入Qoder CN控制台，选择实例管理 > 专属版。

  2. 选择目标组织，单击进入组织详情，可查看当前的域名配置情况，并选取公网访问域名作为专属版域名（domain）。

步骤二：配置专属版的登录地址

在Visual Studio Code中配置专属版的登录地址

  1. 单击侧边导航的Qoder CN图标打开智能会话窗口，并单击右上角的设置按钮。在设置页面，将步骤一中获取的专属版登录地址配置在专属域地址输入框中。

  2. 重新加载或重启 Visual Studio Code 使配置生效。

在JetBrains IDEs中配置专属版的登录地址

  1. 选择文件 > 设置。在设置页面，单击打开Qoder CN菜单，选择专属域账号 ，并将步骤一中获取的专属版登录地址配置在输入框中。

  2. 重启 IntelliJ IDEA 使配置生效。

步骤三：登录Qoder CN

Qoder CN企业专属版支持通过以下两种方式登录：

使用账号密码登录（推荐）

  1. 安装完Qoder CN并需配置专属域账号登录地址后，在 IDE 客户端上选择企业专属域登录完成登录。

    单击 Log in with Enterprise Dedicated URL 选项后，系统将自动复制登录 URL 并在浏览器中打开登录页面，在浏览器中完成登录即可。

  2. 在Qoder CN登录页面中完成登录后，根据当前登录账号与组织关系情况不同决定是否直接登录完成，情况如下：

    • 情况 1：如果当前登录账号仅加入了企业内的单个组织，将默认选择该组织的开发者身份并直接登录完成。

    • 情况 2：如果当前登录账号仅加入了企业内的多个组织，需要选择一个组织的开发者身份登录。

  3. 选择身份后，即可看到登录完成的状态，此时即可前往使用。

    登录成功后，浏览器页面显示Success提示，IDE 右上角将显示已登录的账号名称。

使用个人访问令牌登录

前提条件：获取个人访问令牌。

当您通过IDE远程开发场景中（如使用Remote SSH、WSL、Docker的开发环境），可以使用个人访问令牌登录Qoder CN。

在VS Code、Qoder CN IDE使用个人访问令牌

  1. 在 IDE 中使用快捷键⌘ ⇧ P （CtlShiftP）打开命令面板，搜索Qoder CN，并单击使用 Access Token 登录。

  2. 粘贴个人访问令牌并登录。

    • 如果当前账号仅有一个组织的授权，则单击回车键后即可完成登录。

    • 如果当前账号有多个组织已授权使用Qoder CN IDE，则回车键后，单击选择需要使用的组织即可完成登录。

在JetBrains IDEs中使用个人访问令牌登录

  1. 打开 IDE 的设置页面，找到Qoder CN设置，在未登录状态即可看到 Access Token 登录入口。

  2. 粘贴个人访问令牌并登录。

    • 如果当前账号仅有一个组织的授权，则单击登录即可。

    • 如果当前账号有多个组织已授权使用Qoder CN IDE，需要选择使用的组织，然后单击登录。

登出Qoder CN

  1. 单击Qoder CN智能会话窗口上方的个人头像，然后在下拉菜单中单击退出登录。

  2. 退出后，您将无法使用Qoder CN的代码智能补全、智能会话、行间会话等依赖云端大模型的能力。

本文汇总 Qoder CN 系列产品使用过程中的常见问题与解答，涵盖账号登录、Credits 额度、购买生效、退费续费、QoderWork 及企业版等常见场景。

账号与登录

阿里云账号和 Qoder CN 账号（qoder.com.cn）是什么关系？

Qoder CN 目前有两条产品线，分别使用不同的账号体系：

  • Qoder CN（原灵码）：使用阿里云账号登录，在阿里云控制台 (qoder.console.aliyun.com) 购买和管理。

  • Qoder CN（全家桶）：使用 Qoder CN 账号（在 qoder.com.cn 注册），在 qoder.com.cn 购买和管理。

两套账号通过手机号验证码登录已打通——您可以用同一手机号分别登录阿里云官网和 qoder.com.cn，无需额外配置。但两条产品线的订阅和 Credits 相互独立、不互通。

我不确定自己买的是哪条产品线，怎么判断？

查看您的订单名称或 commodityCode：

  • 含"Qoder CN（原灵码）"或 lingma_ 前缀 → 原灵码线，用阿里云账号登录

  • 含"Qoder CN（全家桶）"或 lingma_CN 全家桶 前缀 → 全家桶线，用 qoder.com.cn 账号登录

如果仍不确定，可登录阿里云控制台查看订单详情中的商品名称。

RAM 子账号能使用 Qoder CN 吗？

可以，但仅限原灵码线的企业标准版/企业专属版。主账号在阿里云控制台完成购买后，为 RAM 子账号分配席位，子账号即可在 IDE 中登录使用。

个人版不支持 RAM 子账号使用——个人版的 Credits 绑定在主账号上，子账号登录后 Credits 为 0，无法使用付费功能。

登录时提示"暂无 Qoder 使用权限"是什么意思？

说明当前登录的账号没有关联任何有效订阅。请确认：

  1. 登录账号与购买时使用的账号是否一致

  2. 如果是企业版成员，确认管理员是否已为您分配席位

  3. 如果购买的是全家桶，确认是否用 qoder.com.cn 账号（而非阿里云账号）登录

qoder.com.cn 是阿里云官网吗？

qoder.com.cn 是 Qoder CN（全家桶）产品线的官方站点，由阿里云运营。它与 aliyun.com 是同一公司的不同产品入口。在 qoder.com.cn 购买的订单，底层仍通过阿里云交易系统完成。

Credits 与额度

原灵码的 Credits 和全家桶的 Credits 能互通吗？

不能。两条产品线的 Credits 完全独立：

  • 原灵码订单的 Credits 只在 Desktop / JetBrains 插件 / VSCode 插件中生效

  • 全家桶订单的 Credits 在 Desktop /JetBrains 插件 /  QoderWork / QoderWake / CLI / Mobile 全线共享

如果您购买了原灵码的订阅，在 QoderWork 中是看不到这些额度的。需要在 QoderWork 中使用，须单独订阅全家桶线。

Credits 用完后会怎样？

Credits 用尽后，高级模型（如 Agent 模式、Quest 等）将不可用，系统会自动切换到基础模型提供有限的代码补全等基础能力。您可以通过购买资源包或等待下一计费周期（Plan Credits 重置）恢复使用。

为什么我的 Credits 消耗比预期多？

不同操作模式的消耗差异很大：

操作

典型消耗

Editor - Ask 模式

~3-4 Credits / 请求

Editor - Agent 模式

~7-12 Credits / 请求

Quest - Agent 模式

~50 Credits / 请求

Quest - Experts 模式

~75 Credits / 请求

常见消耗偏高的原因：Agent 模式会在后台触发多次模型调用，消耗远大于普通 Ask 模式；Quest Experts 模式并行协调多个智能体，消耗最高；对话内容刷新、重试也会产生新的模型调用消耗。如遇系统异常导致的循环刷新，请通过 IDE 内的反馈入口上报问题。

每月的 Credits 什么时候重置？

Plan Credits（订阅包含的额度）的重置周期以购买日为准，而非自然月。例如：7 月 5 日购买，下一次重置为 8 月 5 日。到期时未用完的 Plan Credits 不累积到下个周期，会归零重置。资源包（Add-on Credits）则有独立的有效期，不跟随订阅周期重置。

怎么查看我的 Credits 剩余额度？

  • IDE / JetBrains 插件：窗口右下角点击 Credits 用量按钮

  • QoderWork CN：应用右上角点击 Credits 用量按钮

  • Qoder CN CLI：执行 /usage 命令

  • 官网查看（仅 QoderWork / CLI）：登录 qoder.com.cn → 右上角头像 → Settings > Usage

原灵码线用户在阿里云控制台 (qoder.console.aliyun.com) 查看用量。

Qoder CN 的 Credits 与 Qoder（国际版）的 Credits 等价吗？

不等价。Qoder CN 与 Qoder 定价不同，两者的 Credits 不互通、不可换算。

购买与生效

购买后提示"您已达到配额使用上限"怎么办？

这是最常见的问题，请按以下步骤排查：

第 1 步：退出重登

在 IDE / 客户端中退出账号，重新登录，触发服务端状态刷新。

第 2 步：确认客户端为最新版本

旧版本可能存在状态同步缺陷。在 Help → About 中确认版本号，建议更新到最新版。

第 3 步：确认订单已支付成功

登录对应控制台检查订单状态——部分情况下订单为"待付款"状态，尚未完成支付。

第 4 步：确认账号与产品线匹配

您购买的产品

应使用的登录方式

Qoder CN（原灵码）

阿里云账号

Qoder CN（全家桶）

qoder.com.cn 账号

如果您购买了全家桶但用阿里云账号登录，或反之，则会显示无额度。请切换到正确的账号登录。

刚买了套餐为什么 IDE 里还是显示"体验版"或"Community"？

大多数情况下是客户端状态未刷新。请在 IDE 中完全退出 Qoder CN 账号，关闭 IDE 并重新打开，然后重新登录。如果仍然显示体验版，请确认您登录的账号与购买时使用的账号是否一致。

购买时提示需要实名认证怎么办？

阿里云账号需完成实名认证后才能购买云产品。请前往阿里云实名认证页面完成个人或企业实名认证，认证通过后即可正常购买。

退费与续费

怎么取消自动续费？

  • 原灵码订单：登录阿里云控制台 → 费用中心 → 自动续费管理，找到对应实例关闭自动续费。

  • 全家桶订单：登录 qoder.com.cn → 账号中心 → 订阅管理，关闭自动续费。

关闭后，当前订阅仍可使用至到期日，到期后不再自动扣款，服务降级为 Community 版。

怎么申请退款？

  • 原灵码订单（5 天无理由）：阿里云费用中心 → 退订管理

  • 全家桶订单：qoder.com.cn → 账号中心 → 订阅管理

退款规则以阿里云官方退费政策为准，具体可参见退费说明。

自动退订了但还是扣了费怎么办？

这通常发生在系统自动续费已完成扣款后、因支付方式异常等原因触发退订的场景。此时扣款已实际发生，需要手动通过对应入口申请退款（原灵码订单走阿里云费用中心退订管理，全家桶订单走 qoder.com.cn 账号中心）。

从原灵码升级到全家桶后，原订单怎么处理？

请参见2.2 Credits 资源处理规则中的"原订单退款规则"章节。升级后历史会话数据会无损迁移，不会丢失。原订单的退款和余额处理以该文档为准。

发票与账单

在 qoder.com.cn 购买的订单怎么开发票？

在 qoder.com.cn 购买的订单，底层通过阿里云交易系统完成。您可以使用购买时绑定的阿里云账号登录阿里云控制台，在费用中心 → 发票管理页面提交开票申请。如在阿里云发票管理页面未找到对应账单记录，请确认两边使用的是同一手机号对应的阿里云 UID。

QoderWork

QoderWork 能使用 Token Plan 吗？

不能。QoderWork CN 不支持接入自定义模型的 Token Plan。QoderWork 使用的是订阅套餐内包含的 Credits 额度。Token Plan 仅适用于通过 API 直接调用模型的场景。

QoderWork 频繁报错"Empty response"怎么办？

这通常与网络连接不稳定或服务端瞬时异常有关。请排查：

  1. 确认 QoderWork 为最新版本（Help → About）

  2. 检查网络环境——企业内网、VPN 环境可能导致连接中断

  3. 如果是最新版且网络正常，请通过 QoderWork 内的反馈入口上报，并附上 request_id

执行任务时提示"当前执行已因重复循环被停止"是什么意思？

这是 QoderWork 的安全保护机制——当检测到 AI 在执行过程中进入重复操作循环时，会主动中断以避免无效消耗 Credits。建议将任务指令描述得更具体、明确，然后重新发起。如果同一任务反复出现此提示，请通过反馈入口上报。

为什么我的原灵码订阅在 QoderWork 里看不到额度？

因为原灵码订单的 Credits 不在 QoderWork 中生效。QoderWork 属于全家桶产品线，需要单独订阅 Qoder CN（全家桶）才能在 QoderWork 中使用付费功能。

企业版

企业版怎么给成员分配席位？

根据您的版本：

  • 原灵码企业标准版：管理员登录阿里云控制台 (qoder.console.aliyun.com/instances/teams) → 授权管理 → 添加 RAM 子账号并分配席位

  • 全家桶 Teams 版：管理员登录 qoder.com.cn → 团队管理后台 → 添加成员（支持 SSO 导入）

企业版的 Credits 额度什么时候重置？

企业版席位的 Credits 重置周期按购买日起算，而非自然月。例如：5 号购买，次月 5 号重置。

其他

VSCode 插件还能用吗？

Qoder CN 的 VSCode 插件已停止维护（Deprecated）。建议切换到 Qoder CN Desktop（独立桌面应用，功能最全）或 JetBrains 插件。现有 VSCode 插件用户仍可继续使用，但不再获得新功能更新。

通义灵码改名为 Qoder CN 后，我之前的订阅还有效吗？

有效。品牌升级不影响已有订阅的使用。"通义灵码"与"Qoder CN（原灵码）"是同一个产品的不同名称，您的订阅、Credits、使用记录均保持不变。

Qoder CN Desktop、原 Qoder CN IDE、原 Lingma IDE 有什么区别？

没有区别，是同一款产品的不同历史称呼：Lingma IDE → Qoder CN IDE → Qoder CN Desktop。功能完全一致，仅名称随品牌升级变更。

Qoder CN CLI 内置了国内的 AI 模型，并提供灵活的选择机制，帮助你在开发效率、输出质量与成本之间找到最佳平衡。

模型选择方式

分级模型（Default）

模型分级选择器为开发者提供五个高性能模型池，在成本与性能之间取得不同平衡。如同智能汽车的驾驶模式，为每项任务选用最合适的档位。

自定义模型（Custom）

接入模型厂商提供的订阅计划。Qoder CN CLI 提供了一批受支持的 Provider，用户使用自己在对应厂商的 API Key 即可调用。

支持通过 API 密钥接入第三方供应商的模型资源。

适用版本：个人版
支持的供应商：阿里云百炼、DeepSeek、智谱、Kimi、MiniMax、小米 MIMO

模型参数配置

部分模型支持配置参数，以便更好地适应不同任务类型。可用参数取决于当前模型，CLI 会在 /model 模型列表和模型参数面板中展示当前模型支持的选项。

上下文窗口

上下文窗口控制对话可用的最大上下文长度。常见选项包括：

选项

说明

200K

标准上下文窗口，满足大多数任务需求

400K

扩展上下文，适用于更大的代码库或较长对话

1M

最大上下文，适用于超大规模项目

在 TUI 模式下输入 /context-window 可打开模型参数面板并调整上下文窗口。

思考强度

控制模型在生成回复前的推理深度。可用的选项因模型而异，选择模型后界面会显示该模型支持的档位。

选项

说明

low

最少推理，响应最快

medium

推理深度适中

high

深入推理，适合复杂任务

xhigh

深度分析，适用于高难度问题

max

最大推理深度，适合最复杂的挑战

在 TUI 模式下输入 /effort 可调整当前模型的思考强度。不带参数时打开模型参数面板，也可以直接指定 level：

/effort high
/effort auto --session-only
/effort off

默认会保存到 ~/.qoder-cn/settings.json；加 --session-only 则仅对当前会话生效。

Fast 模式

部分模型提供 Fast 模式，用于优先提升响应速度。开启后 Credit 消耗可能变化，具体以模型参数面板展示为准。

/fast on

支持的模型

目前 Ultimate、Performance、DeepSeek-V4-Pro、DeepSeek-V4-Flash、Qwen3.7-Max、Qwen3.7-Plus、GLM-5.2、MiniMax-M3 和 Kimi-K2.7-Code 支持参数配置。其中 Qwen3.7-Max、Qwen3.7-Plus、GLM-5.2 和 MiniMax-M3 仅支持上下文窗口；Kimi-K2.7-Code 仅支持开启 Fast 模式；其余模型同时支持上下文窗口和思考强度。

切换模型

TUI 中切换

在 TUI 模式下输入 /model 打开选择界面，界面分为 Default、New Models 和 Custom 三个标签页：

/model

↑ / ↓ 选择，Tab 切换标签页，Enter 确认，Esc 关闭。

选择的模型会自动保存到 ~/.qoder-cn/settings.json，下次启动无需重新选择。

命令行参数指定

通过 --model、--reasoning-effort 和 --context-window 参数在启动时直接指定模型设置，仅对本次会话生效：

qoderclicn --model efficient   # Efficient 分级
qoderclicn --model auto        # Auto 分级
qoderclicn --reasoning-effort high
qoderclicn --context-window 400000

列出可用模型

使用 --list-models 可以在无界面模式下输出当前账号可用的模型列表，适合脚本或自动化场景：

qoderclicn --list-models

添加自定义模型

  1. 输入 /model，切换到 Custom 标签页

  2. 选择 Add custom model... 并按 Enter

  3. 按引导依次选择 Provider → 模型类型 → 具体模型

  4. 填写 API Key 等配置信息

  5. 验证通过后自动保存，可立即切换使用

删除自定义模型：在 Custom 标签页选中目标模型后按 d。

说明

本文仅适用于 Qoder CN（全家桶）。不适用于 Qoder CN （原灵码）。

本文介绍 Qoder CN 的账号体系、个人订阅（专业版Pro / 高级版 Pro+）的购买与使用链路，以及企业订阅（团队版 Teams / 企业专属版 Enterprise VPC）的成员角色管理，帮助您理解从下单到使用的完整流程。

重要

  • 此文档仅适用于 Qoder CN（全家桶）客户，即使用 Qoder CN 账号登录。

  • 本文不适用于 Qoder CN（原灵码）的订阅客户。

账号体系

个人用户

个人用户可直接在 qoder.com.cn 完成购买，并查看 Credits 用量。

个人使用的是手机号绑定的阿里云账号；如该手机号未注册阿里云，将在购买时自动创建对应的阿里云账号。客户后续可登录 aliyun.com 查看订单。

团队版用户

企业的采购者前往阿里云控制台完成首次订阅与组织创建。组织日常管理（成员、席位、Credits 用量等）统一在 qoder.com.cn 的企业设置。

仅采购下单的人员需要阿里云账号；其余成员可由企业管理员通过 SSO 导入。

企业专属版用户

企业的采购者前往阿里云控制台完成首次订阅与组织创建。组织日常管理（成员、席位、Credits 用量等）统一在企业专属实例后台。

仅采购下单的人员需要阿里云账号；其余成员可由企业管理员通过 SSO 导入。

账号使用规则

  • 个人版（体验版Free / 专业版Pro / 高级版 Pro+）：必须使用阿里云主账号登录使用。子账号 Credits 为 0，无法使用付费功能（包括 Pro / Pro+ 与 Credits 相关功能）。

  • 团队版Teams / 企业专属版 Enterprise VPC）：必须使用阿里云主账号购买，此账号能采购订阅和分配席位，但是无席位使用资格、也不占用席位费用。

下单要求

  • 需使用实例所属拥有者的阿里云账号或 RAM 用户进行订单相关操作。

  • 推荐使用阿里云主账号下单。如使用 RAM 用户下单，请确保已授予以下权限：

    • 云效产品管理权限：AliyunRDCFullAccess

    • 支付订单权限：AliyunBSSOrderAccess

    • 授权操作请参见管理RAM用户的权限。更多订单权限说明，请参见费用与成本整体权限策略。

购买与使用链路

个人用户在 Qoder.com.cn 即可完成购买、支付与用量查看，无需操作阿里云控制台。Qoder.com.cn 已封装与阿里云购买 API 的交互，整体体验在一个站点内完成。

  1. 手机号注册 / 登录 Qoder.com.cn

  2. 自动选择阿里云 UID（若无 UID，则自动创建）

  3. 在 Qoder.com.cn 下单购买专业版（Pro）或高级版（Pro+）

  4. 支付宝扫码支付

  5. 在 Qoder.com.cn 查看 Credits 用量 / 到期提醒

  6. 下载 QoderWork / Qoder CLI

  7. 通过 SSO 登录使用

账号互通说明

阿里云与 qoder.com.cn 的手机号验证码登录已经打通。客户可使用同一手机号分别登录：

  • 阿里云官网

  • Qoder.com.cn 官网

无需客户额外配置。

说明

设计原则：采购与使用分离。采购在阿里云完成，团队管理统一在 Qoder.com.cn或，产品使用统一在 Qoder CN Desktop、Qoder CN JetBrains插件、QoderWork、Qoder CLI 等客户端。

角色权限详解

配置管理员

企业订阅拥有者，负责首次购买、创建企业组织、后续席位增购、续费管理。

  • 可以：登录阿里云控制台、管理订阅、购买资源包、扩容席位、续费。

  • 不可以：使用企业订阅相关高级功能、访问 Qoder.com.cn 管理后台、管理组织成员、占用企业席位。

说明

一个企业仅允许存在 1 个配置管理员。如需变更，需提交工单处理。

管理员

组织实际管理者，既是计费角色与席位使用者，也是组织管理者。

  • 可以：使用 企业订阅相关全部高级功能、占用企业席位、登录 Qoder.com.cn 管理后台、添加移除成员、分配席位、查看组织用量。

成员

组织内普通使用者，仅是计费角色与席位使用者，不具备组织管理权限。

  • 可以：使用企业订阅相关高级功能、使用企业席位资源、登录并使用Qoder CN Desktop、Qoder CN JetBrains插件、 QoderWork、Qoder CLI。

  • 不可以：访问管理后台、管理组织成员、查看团队统计、增购或续费。

三种角色使用链路

配置管理员链路

  1. 在 qoder.com.cn 询价下单。

  2. 登录阿里云Qoder CN 控制台

  3. 首次购买团队版 Teams 或企业专属版 Enterprise VPC 并创建企业组织，后续增购席位 / 续费

  4. 前往阿里云控制台查看订阅实例状态

  5. 选择对应实例，并免密登录 Qoder 管理后台。

  6. 前往 Qoder CN 官网配置，在设置->安全与身份，为对应组织增加管理员和成员，参考成员和角色。参考域名验证、单点验证、邮件邀请。

管理员链路

  1. 被配置管理员加入企业组织

  2. 获得 Admin 席位

  3. 登录 Qoder.com.cn （企业专属版为企业专属管理入口）

  4. 管理组织成员 / 分配席位 / 查看团队用量

  5. 使用 Qoder CN Desktop、Qoder CN JetBrains插件、QoderWork、Qoder CLI

成员链路

  1. 被管理员加入组织

  2. 获得 Member 席位

  3. 登录 Qoder CN Desktop、Qoder CN JetBrains插件、QoderWork、Qoder CLI

  4. 使用企业订阅相关高级功能

本文是 Qoder CN（原灵码）企业标准版实例的一次性账号升级指南，说明如何把存量企业实例升级为 Qoder CN 全家桶账号，以一份订阅解锁 IDE、JetBrains 插件、QoderWork CN、CLI、Wake、Mobile、Cloud Agents 等全系列产品。

2026 年 6 月前在 Qoder CN（原灵码）与其他 Qoder CN 系列产品，如 QoderWork CN 等是两套账号体系。对于想使用 Qoder CN（原灵码）和 QoderWork CN 两个产品的使用需求，企业需要分别购买独立的订阅。

为保障原企业客户在新体系下平稳过渡、并享受全家桶能力，针对存量企业订阅账号提供一次性升级方案。

重要

此升级操作不可逆，且升级后须切换登录方式，请您务必完整阅读后再升级。

一、升级须知

1、 需先购买目标实例，且席位充足：Qoder CN（原灵码）与 Qoder CN（全家桶）属于不同的商品，无法原地升级。需要客户提前自行购买 Qoder CN（全家桶），Mobile、Cloud Agents），并确保目标实例有足够席位。Qoder CN（原灵码）升级到 Qoder CN（全家桶）遵循 1:1 对应关系：一个老实例 Qoder CN（原灵码）只能升级到一个新实例 Qoder CN（全家桶），升级完成后，这个新实例就与该老实例「绑定」。

2、升级过程不可逆 ： 升级后企业成员将无法通过 Qoder CN （原灵码）实例的账号无法使用 Qoder CN IDE 或 JetBrains 插件登录， 需重新登录到新实例；目标实例的账号由管理员分发给成员，并告知Qoder CN IDE / JetBrains 插件登录方式说明。

3、升级后企业用户需切换方式：升级后企业成员登录新账号可在 IDE 及 JetBrains 插件中，将原实例账号下的 AI 数据（如会话历史 、规则、 记忆 、 智能体 、 代码索引）等迁移到新账号，历史记录不会丢失。

4、升级后 VSC 插件不再支持：如您当前依赖 VSC 插件进行日常开发，建议优先切换至 Qoder CN IDE 或 JetBrains 插件。

5、 请先体验 Qoder CN（全家桶）的企业级管理能力，确认可接受与原灵码的差异。原 通义灵码 企业标准版中的统计报表、知识管理、扩展管理等不再支持，请您使用 Qoder CN（全家桶）相近功能模块如Qoder CN 度量与洞察、企业知识库、扩展与市场等。原通义灵码的策略配置对应功能敬请期待。

三、升级操作步骤

说明：

  • 仅原灵码企业标准版可在控制台自助升级，管理员需通过订阅对应的阿里账号或 拥有对应操作权限的 RAM 子账号登录 Qoder CN 控制台并操作。

  • 企业专属版需提交工单。

具体步骤：

  1. 已经购买 Qoder CN（全家桶） 目标实例 Teams 或 Enterprise 版，并确认可用席位数覆盖现有成员数。

  2. 进入原实例：选择 Qoder CN（原灵码）企业标准版实例，查看实例详情。

  3. 发起升级：点击「立即升级」，详细阅读升级须知并按步骤执行。

  4. 选择目标实例：在候选列表中选择目标实例，系统会校验席位是否充足；若席位不足会给出提示，建议增购后再继续。

  5. 确认升级须知：阅读并确认退款、credits 转移、不可逆等相关条款。

  6. 完成升级：确认后完成升级，可在控制台查看新实例状态。升级通常在分钟级完成。

四、升级后操作指引

升级完成后，建议管理员按以下顺序完成后续操作：

1. 配置成员登录方式

为目标实例的成员配置登录方式。如企业原使用阿里云 RAM 账号登录，需在 Qoder CN（全家桶）中开启 RAM OAuth 应用并完成配置（详见 FAQ「RAM 账号登录」相关问题）。

2. 通知企业成员

告知全体成员升级已完成，并发送以下信息：新实例的登录入口与登录方式；原实例的会话历史迁移操作说明；VSC 插件用户需切换至 IDE 或 JetBrains 插件。

3. 协助成员迁移会话历史

成员可在 IDE / JetBrains 插件中将原实例账号下的会话历史合并到新实例（操作详见登录与迁移指引）。

4. 处理原实例（可选）

确认所有成员已完成迁移后，管理员可决定是否删除原实例。原实例在升级后不可续费，但可继续访问直到管理员手动删除。

企业用户如何迁移原灵码的AI数据？

升级后企业成员登录新账号可在 IDE 及 JetBrains 插件中，将原实例账号下的 AI 数据（如会话历史 、规则、 记忆 、 智能体 、 代码索引）等迁移到新账号，历史记录不会丢失。

常见问题（FAQ）

升级与回退

Q：升级可以撤销 / 回退到原灵码吗？

A：不可以。升级为不可逆操作，一旦完成无法退回到 Qoder CN（原灵码）。请在升级前确认已购买好目标实例、席位充足，并知悉退款与 credits 转移规则。

Q：升级需要多久？升级期间成员还能正常使用吗？

A：企业标准版升级分钟级完成。升级期间成员不可使用。

Q：升级后原实例还能续费吗？还能登录吗？

A：升级后不可续费。建议尽快完成成员向目标实例的迁移。

目标实例选择

Q：我已经有 Qoder CN（全家桶）的企业订阅，为什么升级时选不到目标实例？

A：升级选不到目标实例，通常是以下两种情况之一，请对照排查：

  1. 目标实例订阅不生效或已过期。 升级只能选择处于有效期内的 Qoder CN（全家桶）实例作为目标。请先到控制台确认该订阅仍在有效期、未欠费停服。

  2. 该目标实例已被用作过一次升级目标。Qoder CN（原灵码）升级到 Qoder CN（全家桶）遵循 1:1 对应关系：一个老实例（原灵码）只能升级到一个新实例（全家桶），升级完成后，这个新实例就与该老实例「绑定」了，不能再作为其他实例的升级目标。如果您还有其他原灵码实例需要升级，请为其单独购买一个新的 Qoder CN（全家桶）实例作为目标。

补充：升级后，企业成员可在 IDE 及 JetBrains 插件中，将原实例账号下的会话历史迁移到新实例，历史记录不会丢失。

Credits 与退款

Q：原实例里的 credits 和资源包会怎么处理？多久到账、有效期多久？

A：本周期已分配且已激活席位的 credits 会转入目标实例，有效期 1 个月；企业共享资源包 credits 转入后有效期 3 个月；无 credits 机制的原实例不涉及 credits 转移。

Q：退款怎么计算、退到哪里、多久到账？

A：仅对后续周期订阅与续费订单退款，本周期已使用部分不退。退款原路退回至支付账号，资金通常会在 1-7 个工作日内退回到您的原支付渠道（支付宝/银行卡），具体到账时间取决于银行处理时效。

RAM 账号登录

Q：企业成员之前灵码中通过阿里云 RAM 账号登录，升级到 Qoder CN（全家桶）是否支持？

A： 支持。Qoder CN （全家桶）Teams、Enterprise 版订阅均支持阿里云 RAM 账号登录。管理员需在 Qoder CN（全家桶）中，开启Qoder CN 的 RAM OAuth 应用，并按步骤完成相关配置。

请注意以下限制：

  • 一个阿里云 RAM 账号仅能关联到一个 Qoder CN（全家桶）企业实例。

  • RAM 账号只能登录其所属阿里云主账号名下的企业实例，不支持跨账号 ID 登录。

且仅支持 Teams、Enterprise 版订阅。同时，对应Qoder CN（全家桶）企业实例必须是 RAM 账号归属的阿里云账号 ID 所持有的，即不能跨账号授权实例。

本文介绍 Qoder CN（原通义灵码）的账号体系、两种订阅版本、企业组织角色，以及订阅续费、变配、退费等全生命周期操作的入口，帮助您完成从下单到使用的全流程。

说明

本文仅适用于 Qoder CN（原通义灵码）。如使用 QoderWork CN 或 Qoder CN CLI，请参见 Qoder CN（全家桶） 账号与订阅。

账号体系

Qoder CN 沿用阿里云账号体系，购买与登录均使用阿里云账号，无需额外注册。

  • 阿里云主账号：用于下单购买、订阅管理、账单查询。个人版用户使用主账号即可完成全部操作。

  • RAM 子账号：企业可在阿里云 RAM 控制台创建并授权子账号，用于成员日常使用。子账号无法独立购买订阅，但可在主账号授权的范围内使用 Qoder CN。

说明

企业版的 RAM 授权策略请参见阿里云 RAM 文档。

购买与开通

企业标准版

  1. 阿里云主账号在 Qoder CN 控制台 创建 Qoder 组织。

  2. 在购买页面为此 Qoder 组织订阅企业标准版，购买所需席位数。

  3. 回到 Qoder CN 控制台选择对应企业标准版，访问实例并分配席位给指定 RAM 子账号或同账号下的成员。

  4. 成员在 IDE 中通过 Coding APP 登录获分配席位的账号，开始使用。

企业专属版（VPC）

企业专属版采用定制化交付模式，包含 VPC 私有部署、专属资源池等能力。请联系商务获取方案与报价。

客户端登录与使用

完成购买与席位分配后，开发者在 IDE 中使用 Qoder CN 的步骤如下：

  1. 在 JetBrains IDE 或 VS Code 中安装 通义灵码（Qoder CN） 插件。

  2. 点击插件登录入口，在浏览器中通过 Coding APP 完成阿里云账号扫码授权。

  3. 登录成功后，IDE 中的能力按所登录账号绑定的订阅版本与席位生效。

说明

登录账号需与购买时使用的阿里云主账号、或被分配席位的 RAM 子账号一致；否则将无法使用付费功能。

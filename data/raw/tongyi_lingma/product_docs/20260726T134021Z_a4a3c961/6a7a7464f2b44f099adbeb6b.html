Qoder CN企业标准版开发者可以使用阿里云账号登录Qoder CN ，本文介绍企业标准版开发者登录操作指南。

登录Qoder CN

步骤 1：准备工作

  • 已成功注册阿里云账号，具体操作可参考：账号注册（PC端）；

  • 已在组织中被授权开发者权限，如未获得权限，可联系组织内的Qoder CN管理员添加权限，可参考：授权管理；

  • 已在 JetBrains IDEs、Visual Studio Code、Visual Studio 中安装Qoder CNIDE 插件、或下载安装 Qoder CN IDE，具体操作可参考：安装指南。

步骤 2：在 IDE 的Qoder CN登录

说明

如果你的电脑安装多个 IDE 本地客户端，登录状态在多个 IDE 客户端的Qoder CN中同步，您只需要登录一次即可。

登录Qoder CN企业标准版有以下方式，请根据您具体得使用场景进行选择：

  • 使用账号登录（推荐）

  • 使用 AK/SK 登录

  • 个人令牌登录

方式 1：使用账号登录Qoder CN（推荐）

  1. 安装完Qoder CN后，选择阿里云中国站账号登录，前往阿里云登录页完成登录：

    在 IDE 侧边栏的Qoder CN插件面板中，单击阿里云中国站账号登录按钮，浏览器将自动跳转至阿里云登录页面。

  2. 在阿里云登录页面中，完成阿里云登录（RAM 用户可在 RAM 用户登录页面中登录）后，将根据当前登录账号与组织关系情况不同，可选择不同的身份，情况如下：

    • 情况 1：如果当前登录账号为阿里云账号，可选择以个人身份登录或组织内开发者身份登录，此时需选择以组织开发者身份登录；

    • 情况 2：如果当前登录账号为 RAM 用户，当你仅加入1个标准版组织且被授予开发者权限时，将默认选择该组织开发者身份并进入下一步；当你加入了多个标准版组织，同时被为多个组织授予开发者权限时，需要选择一个开发者身份登录。

  3. 选择身份后，即可看到登录完成的状态，此时即可使用。

方式 2：使用阿里云账号的 AK/SK 登录Qoder CN

如果遇到无法打开浏览器的阿里云登录页面时，可使用阿里云账号的 AK/SK 登录Qoder CN，情况如下：

  • 当您进行远程开发时，如使用 Remote SSH、WSL、Docker 的开发环境，可以使用 AK/SK 的方式登录Qoder CN；

  • 当您使用 Visual Studio Code 的 Web IDE 时，可以使用 AK/SK 的方式登录Qoder CN；

  • 当您使用基于 Visual Studio Code 的 Web IDE 开源版本构建的 IDE 时，如果 IDE 提供方对接了 Open VSX 时，可以使用 AK/SK 的方式登录Qoder CN，直达地址：https://open-vsx.org/extension/Alibaba-Cloud/tongyi-lingma；

  • 其他无法打开阿里云登录页面的情况。

操作步骤如下：

  1. 前往阿里云控制台获取 AccessKey，具体操作可参考：创建AccessKey。

  2. 在Qoder CN的登录配置中输入 AccessKey ID、AccessKey Secret 进行登录，不同 IDE 客户端中操作不一样（如下图所示），操作如下：

    • VS Code、Qoder CN IDE：在 IDE 中使用快捷键⌘ ⇧ P （CtlShiftP）打开命令面板，搜索 Qoder CN，即可看到使用 AK/SK 登录Qoder CN，单击后分步输入 AccessKey ID、AccessKey Secret，选择身份（未加入任何企业时将跳过）单击Enter/Return键，即可完成登录；

    • JetBrains IDEs：打开 IDE 的设置页面，找到Qoder CN设置，在未登录状态即可看到 AK/SK 登录入口，输入 AccessKey ID、AccessKey Secret 后，选择身份（未加入任何企业无需选择），然后单击登录即可；

    • 暂不支持在 Visual Studio 中使用 AK/SK 登录。

方式 3：使用个人访问令牌登录Qoder CN（VS Code）

说明

如需使用个人访问令牌登录，请确保将Qoder CN IDE 升级到 V1.4.1 及以上；

当使用 VS Code 本地 IDE、WebIDE、远程开发模式（如 Remote SSH、WSL、Docker 的开发环境）时，组织标准版的开发者均可以使用个人访问令牌（Access Token）进行登录。操作步骤如下：

  1. 前往组织标准版的个人访问令牌管理，直达链接：获取个人访问令牌；

  2. 创建个人访问令牌，并选择权限为：Qoder CN-开发者-只读，新建完成后复制个人访问令牌；

  3. 使用个人访问令牌，不同 IDE 客户端中操作不一样，操作如下：

    • VS Code、Qoder CN IDE：在 IDE 中使用快捷键⌘ ⇧ P （CtlShiftP）打开命令面板，搜索 Qoder CN，即可看到使用 Access Token 登录Qoder CN，黏贴第二步复制的个人令牌，如果当前账号仅有一个组织的授权，则单击回车键后即可完成登录，如果当前账号有多个组织已授权使用Qoder CN IDE ，则回车键后，单击选择需要使用的组织即可完成登录；

    • JetBrains IDEs：打开 IDE 的设置页面，找到Qoder CN设置，在未登录状态即可看到 Access Token 登录入口，黏贴第二步复制的个人令牌，如果当前账号仅有一个组织的授权，则单击登录即可，如果当前账号有多个组织已授权使用Qoder CN IDE，需要选择使用的组织，然后单击登录；

登出Qoder CN

单击Qoder CN智能会话窗口上方的账号信息，然后单击退出。

退出后，您将无法使用Qoder CN的代码智能补全、智能会话、行间会话等依赖云端大模型的能力。

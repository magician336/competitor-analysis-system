2026年05月20日 v1.0.0

Qoder CN CLI 1.0 重磅发布

新功能

  • 云端运行：支持 qodercli --remote flag，Cloud 模式支持任务一次性提交云端容器，关机断网不影响执行，支持数小时长时工作流；

  • RepoWiki：支持 qodercli wiki 子指令，代码不出域本地生成 repowiki 文档；

  • Voice：支持 /voice 指令，语音输入能力全面升级，免费开放；

  • Goal：支持 /goal 指令，面向目标长程任务执行不跑偏；

  • 开放模型参数：支持自定义 efforts 档位 以及支持 1M 上下文窗口设置：

面向企业开放被集成能力

  • Agent SDK：支持 TypeScript 和 Python，几行代码即可集成完整 Agent 能力；编程级控制（工具授权回调、执行前拦截、参数修改）；

  • Cloud Agents：Agents 即服务，沙箱隔离、状态管理、异步编排、凭证管理、长时运行平台内置；

核心能力升级

  • 编排：任务自动拆分多 Agent 并行执行，主 Agent 判定拆分策略，子 Agent 独立事件循环；

  • 扩展：支持 Skills / Hooks / MCP / Subagent / Command 五类正交扩展点；

  • 自治：Agent 自判风险，仅关键节点请求确认；LLM / SLM / VLM 自动路由；

  • 集成：Headless（CI/CD 无人值守）、ACP（标准双向通信）、SDK（TS / Python）三种接入形态

欢迎使用 Qoder CN CLI！

你好，我是 Qoder CN CLI！很高兴认识你。

我将把强大的 AI 辅助开发能力直接带到你的终端——那个你高效工作的场所。无需上下文切换，也无需笨重的 IDE，只有你和你的命令行，以及一位真正理解你代码库的 AI 伙伴。

我们的协作方式如下：

  • Quest Mode：将复杂任务交给我。只需描述你的需求，我会设计解决方案、跨文件实现代码、运行测试，并交付可运行的成果。让你专注于最重要的事情——其余交给我处理。

  • Agent Mode：通过对话进行编码。关于项目有任何疑问，我都能帮你调试、重构或实现新功能，并全程由你掌控。结合完整代码上下文，为你提供即时精准的答案。

  • 自定义 Commands & Subagents：将重复性工作流转化为可执行命令。无论是生成数据库迁移脚本、更新文档，还是运行安全检查——团队的知识都将变成自动化能力。

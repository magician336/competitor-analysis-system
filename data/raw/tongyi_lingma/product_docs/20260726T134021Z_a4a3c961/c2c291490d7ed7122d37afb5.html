邮件邀请

企业管理员完成 QoderWork CN / Qoder CN CLI 订阅购买后，可以通过“邮件邀请”功能批量邀请团队成员加入组织。被邀请的成员通过邮箱收到带邀请码的链接，按引导完成注册并设置初始密码后即可登录使用。本文介绍管理员如何发送邀请邮件，以及成员如何接受邀请。

功能介绍

邮件邀请功能允许管理员在 Qoder CN 官网 一次性向多个企业邮箱发送加入邀请。

整体流程如下。

┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│ 1. 管理员已有    │ →  │ 2. 管理员输入    │ →  │ 3. 成员查收邮件     │ →  │ 4. 成员登录      │
│    可分配席位     │    │    成员邮箱并   │    │    凭邀请码注册     │    │    QoderWork CN │
│                 │    │    发送邀请     │    │    并初始化密码     │    │    使用         │
└─────────────────┘    └─────────────────┘    └─────────────────┘    └─────────────────┘

前提条件

  • 已购买QoderWork CN / Qoder CN CLI 企业标准版（Teams）订阅，且当前账号为该组织的管理员，并持有相应数量的可分配席位。

步骤一：发送邀请邮件

域名验证通过后即可发送邀请。邀请由两步向导完成：邀请设置和添加成员。

1.1 进入邮件邀请配置

  1. 在 设置 > 访问与身份验证 页面，下滑至 成员配置 > 邮件邀请 区域。

  2. 点击 配置 按钮，打开“邀请成员加入企业”对话框。

1.2 配置邀请设置（第 1 步）

在向导第 1 步中设置邀请有效期和成员身份：

  • 邀请链接有效期：默认 1 小时，最长可设置为 48 小时。超时后链接和邀请码将自动失效，需重新发送邀请。

  • 邀请成员身份：本次发送的所有邀请将赋予相同角色，加入后可单独修改。

    • 成员：可使用工作台与 AI 编程能力，无独立计费，无管理权限。

    • 管理员：除拥有成员能力外，可管理成员、计费与企业设置。

完成后点击 下一步。

1.3 添加成员邮箱（第 2 步）

在向导第 2 步中录入需要邀请的企业邮箱：

  • 系统支持两种录入方式：

    • 逐条添加：直接在输入框填写邮箱，点击 添加一行 继续追加。

    • 批量导入（如已开通）：邮箱框粘贴多行邮箱地址，系统批量填充并自动解析。

  • 单次最多发送 200 封 邀请邮件。

确认无误后，点击 发送邀请。系统将立即向每个邮箱发送一封邀请邮件，邮件内含一次性邀请码与注册链接。

说明

邀请发送后可在 成员管理 页面 成员 > 邮件邀请 Tab 查看邀请名单、邀请状态、剩余有效期，并支持单条重发、取消和删除。

步骤二：成员接受邀请并完成注册

被邀请的成员将在邮箱中收到一封来自 qoder.com.cn 的加入邀请邮件。

2.1 查收邮件并打开注册页

成员打开邮件，点击 加入企业 按钮，浏览器将跳转至 Qoder CN 的“加入企业”页面。该页面已自动带入被邀请的邮箱地址。

提示：若按钮无法打开（如跨设备或邮件客户端拦截），可手动复制邮件中的链接打开，并使用邮件中的 6 位邀请码手动验证。

2.2 输入邀请码并设置初始密码

在“加入企业”页面，依次完成以下操作：

  1. 邀请码：粘贴或输入邮件中收到的 6 位邀请码（点击邮件按钮跳转的链接通常已自动填写）。

  2. 设置密码：至少 8 位，包含大小写字母与数字，建议混合大小写字母、数字与符号。

  3. 确认密码：再次输入相同密码。

  4. 勾选 我已阅读并同意《服务条款》与《隐私政策》。

  5. 点击 加入企业并完成注册。

注册成功后，成员账号自动加入企业组织，并被赋予管理员在邀请时配置的角色。

说明

邀请码具有时效性（默认 1 小时，由管理员配置）。若超时或邀请被撤回，需联系管理员重新发送。

步骤三：成员登录使用

注册完成后，成员可以通过以下入口登录 Qoder CN：

  • 官网：qoder.com.cn，使用注册邮箱 + 初始密码登录。

  • IDE 插件 / 客户端：在登录入口选择 Qoder CN 账号登录，输入相同的邮箱与密码即可。

首次登录后建议成员前往 个人设置 完善昵称、头像，并根据需要开启二次验证（MFA）。

常见问题

Q1：邀请邮件发出后多久会送达？成员没收到怎么办？

邀请邮件通常在 1 分钟内送达。若超过 5 分钟仍未收到，请按以下顺序排查：

  1. 查看垃圾邮件 / 广告邮件文件夹。

  2. 确认企业邮箱网关未拦截 noreply@qoder.com.cn 域名。

  3. 在管理员侧 成员管理 > 待加入 Tab 中点击 重发邀请。

    重要

    同一封邀请的重发有 24 小时冷却期，冷却期内重复点击不会触发新邮件。

  4. 若重发后仍未收到，请联系 Qoder CN 客服排查邮件发送状态，确认问题解决后再重新发起一次邀请。

Q2：邀请链接 / 邀请码过期了怎么办？

链接和邀请码过期后无法继续注册。需联系企业管理员在 成员管理 > 已过期 Tab 中找到对应成员并 重发邀请，新邀请码将重置有效期。

Q3：单封邀请邮件能多人共用吗？

不可以。每封邀请邮件中的邀请码与目标邮箱绑定，仅供该邮箱注册使用。请管理员为每位成员单独发送邀请。

Q4：成员注册后想要修改邮箱怎么办？

注册邮箱与企业组织成员身份绑定，暂不支持成员自助修改。如需更换邮箱，请联系管理员将原账号移除，并使用新邮箱重新发送邀请。

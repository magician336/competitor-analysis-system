0.0.24（2026-06-16）

新建项目与项目来源配置优化

  • 体验优化

    • 项目来源
      添加项目来源时，只要在最后一行选好有效的本地目录或填写有效的 Git 仓库地址，保存按钮即可使用并提交该来源，无需先点击「添加」。

  • 问题修复

    • 修复在工作目录选择器中新建项目后未自动选中该项目且工作目录不正确的问题；现在新建的项目会被自动选中并使用正确的工作目录，使之后发送的任务能在正确的工作目录下运行。

0.0.23（2026-06-16）

项目上下文来源编辑修复

  • 问题修复

    • 修复创建项目时，删除多余的空白上下文来源（Context Source）草稿行可能误删已添加来源的问题。

0.0.22（2026-06-16）

更新提醒优化

  • 体验优化

    • 更新提醒
      当更新版本已下载并准备就绪时，界面右下角会出现可关闭的更新提醒，你可以选择立即更新、关闭或稍后处理；关闭后提醒会保持隐藏，直到有更新的版本准备就绪。

0.0.21（2026-06-13）

API 触发器、登录即启动、闲时更省资源

  • 新增功能

    • API 触发器
      现可为自动任务配置 API 触发器，通过向指定地址发送请求即可按需主动拉起 Waker 执行任务，此前已支持的自动化触发方式继续可用。

  • 体验优化

    • 登录时启动
      新增系统设置项，可让 QoderWake CN 后台服务在系统登录后自动启动。macOS 菜单栏的「登录时启动」开关与 Console 中的设置现已保持同一状态。

    • MCP 连接器自动恢复
      当远程 MCP 连接器的 OAuth 客户端过期时，现可自动且无感地重新建立连接；若恢复失败，则提供「重新授权」按钮作为兜底。

    • 用量面板优化
      用量概览现以固定浮层形式锚定在应用侧栏，并在每次打开时刷新；全局的更新／重启提示不再与设置界面相互遮挡。

  • 问题修复

    • 修复打开或刷新无效或不可用的 Console 链接（例如会话或资源已不存在）时显示空白或报错页面的问题，现会跳转回对话主页。

    • 修复了应用空闲时占用 CPU 过高的问题，在无任务运行时显著降低资源占用。

0.0.20（2026-06-12）

重启提示更智能、Waker 主页内容更及时、Console 访问更稳定

  • 体验优化

    • 更智能的重启提示
      更新后的重启提示仅在确有进行中的对话时才提醒可能被打断，空闲会话不再误触发。

  • 问题修复

    • 修复 Waker 主页「关于我」（核心能力、工作风格、交付承诺）在其他位置修改后仍展示过期缓存内容的问题。

    • 修复直接访问或刷新 Console 深层链接（如会话页、Waker 主页）时白屏或报错的问题。

0.0.19（2026-06-11）

全局设置上线、IM 文件变更摘要更清晰、会话运行更稳定

  • 新增功能

    • 全局设置
      设置菜单新增独立的「全局设置」页，可单独设置 AI 默认回复语言（独立于界面语言，应用于新建会话），开启「运行期间防止系统休眠」，并集中提供网络诊断与应用更新入口，同时适配浅色/深色主题。

  • 体验优化

    • 文件变更摘要
      IM 渠道的最终答复现在会附上本轮运行的文件变更摘要，以相对路径展示，便于确认交付范围。

    • 升级重启提示
      完成更新后，控制台会显示统一的升级重启提示，并在重启前说明当前是否有会话或自动任务正在运行，帮助你决定何时重启。

    • 会话稳定性
      控制台不再在底层进程异常结束后一直卡在「思考中…」加载态，并在启动期偶发网络/注册异常时仍能可靠地新建会话。

  • 问题修复

    • 修复钉钉等 IM 渠道有时把子代理的中间内容当作最终答复返回的问题，现在只返回真正的最终结果。

0.0.18（2026-06-10）

Skill 市场自进化、记忆成长时间线与空闲记忆沉淀

  • 新增功能

    • Skill 市场与自进化
      支持上传自己的 Skill，并在上传时和详情页选择是否允许自进化，附带"自进化"标识。市场中的 Skill 受保护、只读，不可编辑或自进化。当自进化产生冲突时，输入框上方会出现提示面板，可选择忽略或立即处理，并通过左右对照的 AB diff 视图进行手动编辑。

    • 记忆成长时间线
      Waker 主页新增记忆与 Skill 演进的鱼骨时间线，每条记忆事件独立成节点，点击节点可在页内打开记忆版本面板，并包含 Skill 生命周期治理节点。

    • 空闲轮次后台记忆
      在对话轮次之间的空闲间隙，Waker 会自动沉淀核心记忆（用户画像、项目/账号定义、长期目标与约束），无需在主对话中显式触发记忆操作。

  • 体验优化

    • Skill 血缘视图
      血缘视图改为展示「项目 -> Waker Skill」的贡献关系，并分别展示引用次数与使用次数；同时移除了项目级 Skill 界面。

    • /wake 会话身份
      通过 /wake 发起的 IM 会话现在与常规 IM 会话保持一致的发送者身份和工作区上下文。

    • 更大的 IM 文件支持
      钉钉、飞书、企业微信机器人、微信等 IM 渠道的文件上限由 20 MB 提升至 100 MB；文件超限时会给出明确提示，不再静默失败。

  • 问题修复

    • 修复 Waker 列表「最近对话时间」被触发器/自动化运行误刷新的问题，现在能真实反映对话活动。

    • 修复进程正常运行时会话误报「启动失败」的问题。

    • 修复控制台记忆预览中有序/无序列表标记显示异常的问题。

0.0.17（2026-06-09）

IM 新建对话任务指令、对话控制增强与稳定性修复

  • 新增功能

    • IM 新建对话任务指令
      在 IM 中发送 /wake 即可新建一个对话任务，后续消息自动进入新对话，无需手动重建。

  • 体验优化

    • IM 消息身份感知
      IM 对话现会记录发送者身份，Waker 可识别消息来自哪个渠道、哪个用户。

    • IM 控制模式安全限制
      IM 中新建对话仅可通过专用指令触发，禁止直接执行系统命令或文件操作。

    • IM 文件权限优化
      权限校验现已放行安全的系统临时目录和特殊设备路径（如 /dev/null），减少误拦截。

    • IM 会话交互限制
      IM 会话中不再触发交互式等待提问，避免在异步消息场景中产生无法处理的阻塞。

    • CLI 升级
      Qoder CLI 升级至 1.0.14。

  • 问题修复

    • 修复 IM 中会话阻塞时错误处理不一致的问题，阻塞会话现会被正确终止，下一条消息可自动新建会话。

    • 修复 IM 回复在部分场景下发送到错误上下文的问题。

    • 修复文件/目录选择器可被连续触发多次，导致重复弹窗的问题。

    • 修复禁用或删除 MCP 服务后，同步机制可能将已禁用的服务恢复的问题。

    • 修复 MCP 鉴权失败后状态显示不准确的问题，现已正确标记为鉴权失败。

0.0.16（2026-06-08）

IM 渠道工作目录配置与会话权限优化

  • 体验优化

    • IM 渠道工作目录
      所有 IM 渠道（钉钉机器人、钉钉个人、钉钉 AI 助理、飞书、微信、企业微信）现已支持设置工作目录，可选择本地文件夹或绑定已有项目；未设置时沿用默认目录。

    • IM 配置页项目选择
      工作目录选择器中可查看私密和公开项目，支持直接新建项目；选择后可用模型列表自动刷新。

    • 目录无感切换
      修改 IM 渠道工作目录后，已有会话在下一条消息到达时自动使用新目录，无需重建渠道。

    • 权限校验增强
      IM 会话权限校验现会识别已配置的工作目录，减少因目录变更导致的访问拦截。

  • 问题修复

    • 修复 IM 群聊中多人连续发消息时，最终回复可能错误使用下一位发送者上下文的问题。

    • 修复钉钉个人渠道授权缺失时只在后台静默失败的问题，现在渠道状态中会展示重新授权链接。

    • 增加工作目录路径校验，避免保存无效路径配置。

钉钉渠道优化与配置体验优化

  • 体验优化

0.0.10（2026-05-26）

QoderWake CN 正式开启全球公测

QoderWake CN 是一款 AI 数字员工运行时平台，可以让你在本机组建一支"数字员工"团队（Wakers）。每个员工有岗位、有名字、有人设、有专长，可以被你召唤聊天或干活。此次公测为 Beta 版本，支持 macOS（13+）、主流 Linux 系统，暂未开放 Windows 版本。

  • 数字员工

    • 创建多个员工，每个拥有独立身份、记忆、技能和工作空间。

    • 内置多种角色模板（软件工程师、QA、产品经理、数据分析师、内容运营专员等），也支持完全自定义角色。

    • 通过自然语言对话直接派发任务，实时查看思考过程、代码产出和工具调用。

    • 员工执行敏感操作前会主动征求同意，支持三档权限策略（允许/询问/禁止）。

  • 自动化触发器

    • 支持定时、GitHub Webhook 等多种触发方式。

    • 提供运行历史、日历视图、月度统计、执行次数限制等管理能力。

    • 支持保存前"测试拉取"，只读验证数据源连通性。

  • Skill 与工具集成

    • 内置技能开箱可用，技能市场一键安装，也支持上传自定义技能包及自动沉淀 Skill。

    • 支持 MCP 协议接入外部工具，完整 OAuth 2.0 授权流程。

    • 工具级别精细开关控制。

  • 长期记忆

    • 跨会话持久化记忆，按板块组织（用户偏好、项目知识、关键决策等）。

    • 支持个人记忆和项目级共享记忆。

    • 内置语义搜索、每日自动整理、版本快照与回滚。

  • 多渠道接入

    • Web Console：本地可视化管理界面，覆盖所有操作，支持暗色主题和语言切换。

    • IM 渠道：支持将员工接入钉钉等 IM 平台，在群聊或私聊中直接交互。

    • CLI：完整命令行工具，含进程管理、运维诊断、备份恢复等。
